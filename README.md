# Clara Dental Reservation MVP

Simple Next.js booking experience for a dental clinic. The UI is demo-ready with a Supabase schema included in `supabase/schema.sql` for appointment persistence.

## Run locally
`npm install` then `npm run dev`

## Supabase
Create a project, run the SQL schema, then copy `.env.example` to `.env.local` and add the project URL and publishable key.
